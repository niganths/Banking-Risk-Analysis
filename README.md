# Banking Risk & Control Analytics

A banking analytics project built using **Python and Power BI** to understand customer financial exposure, identify data issues, and analyze risk patterns across 3,000 customer records.

### What I did

- Cleaned and explored the banking dataset using **Pandas, NumPy, Matplotlib and Seaborn**.
- Performed **univariate, bivariate and multivariate analysis** on customer and financial attributes.
- Created indicators such as **Loan-to-Income, Loan-to-Deposit, Business Lending-to-Income and Debt-to-Liquid Assets**.
- Found **60 duplicate Client IDs**, along with customers crossing selected exposure thresholds.
- Built a **3-page Power BI dashboard** to track exposure, exceptions and differences between calculated indicators and existing risk classifications.

### Tools Used

**Python | Pandas | NumPy | Matplotlib | Seaborn | Power BI | DAX | Excel**
